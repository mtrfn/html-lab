DB-Lab în clasa Teams

Înregistrare Microsoft separată de HTML-Lab. Aplicația rămâne pe GitHub Pages; nu are nevoie de un server Azure pentru această etapă.

V1.3 adaugă conectarea, confirmarea clasei și citirea lecțiilor din SharePoint. Lucrările elevilor se salvează încă local. Predarea temelor, notarea și sincronizarea între dispozitive nu sunt incluse.

1. Înregistrează aplicația DB-Lab

  1. Cu contul administratorului, intră în Microsoft Entra. Deschide App registrations → New registration.
  2. Nume: DB-Lab. Alege conturi doar din organizația școlii (Single tenant), apoi înregistrează aplicația.
  3. Din Overview copiază Application (client) ID și Directory (tenant) ID. Sunt identificatori publici, nu parole.
  4. În Authentication adaugă platforma Single-page application și URI-ul brk-multihub://mtrfn.github.io. Nu adăuga /db-lab/ aici. Dacă schimbi domeniul de găzduire, folosește domeniul nou.
  5. În API permissions adaugă Microsoft Graph → Delegated permissions: User.Read (profil), EduRoster.ReadBasic (apartenența la clase și clasele predate), Files.Read.All (citirea fișierelor accesibile utilizatorului, inclusiv biblioteca clasei). Ultima permisiune permite citirea tuturor fișierelor la care utilizatorul are acces; codul DB-Lab cere doar biblioteca clasei.
  6. Administratorul autorizat al școlii verifică și acordă consimțământul organizației pentru aceste permisiuni. Dacă rolul tău nu permite aprobarea, solicită administratorului cu drepturile necesare.

Nu crea Client secret, permisiuni Application sau un API propriu. Autentificarea folosește NAA în Teams. Aprobarea permisiunilor se face în Entra.

2. Generează configurația și pachetul Teams

Deschide această pagină de pe site-ul publicat (sau un server local), completează identificatorii și descarcă cele două fișiere. Formularul generează fișierele în browser și nu trimite identificatorii unui serviciu de configurare.

  1. Încarcă întregul conținut al folderului db-lab V1.3 în repository-ul GitHub publicat, apoi înlocuiește microsoft-config.js cu fișierul generat.
  2. Așteaptă publicarea GitHub Pages. Deschide site-ul și verifică antetul V1.3.0. Păstrează structura folderelor și fișierele vendor.
  3. În Teams admin center, în administrarea aplicațiilor, încarcă DB-Lab-Teams-V1.3.zip ca aplicație proprie și permite utilizarea sa pentru conturile pilot, conform politicilor școlii. Nu încărca arhiva completă a site-ului ca aplicație Teams.
  4. Într-o clasă Teams, într-un canal standard, adaugă fila DB-Lab și apasă Salvează. Conectează-te cu contul folosit în Teams. Nu este o filă pentru chat-uri sau canale private/partajate.

3. Publică lecțiile clasei

  1. În DB-Lab deschis în browser, folosește Atelierul pentru lecții proprii. Exportă biblioteca din Lecții SQL. Poți începe cu fișierul celor opt lecții incluse.
  2. În site-ul SharePoint al clasei deschide biblioteca implicită de documente. La rădăcina bibliotecii creează folderul DB-Lab; încarcă biblioteca sub numele exact lectii.json. Calea trebuie să fie DB-Lab/lectii.json, nu General/DB-Lab/lectii.json.
  3. Configurează permisiunile folderului: profesorii pot modifica, elevii pot citi. Bibliotecile de clasă pot permite implicit editarea elevilor, deci verifică accesul efectiv în SharePoint. Ascunderea atelierului nu înlocuiește aceste permisiuni.
  4. În fila DB-Lab apasă Actualizează lecțiile clasei. Deschide Lecții SQL și grupul Lecțiile clasei.

4. Verifică folosind două conturi

  • Profesorul clasei: identitate corectă, bibliotecă încărcată, atelier vizibil.
  • Elevul aceleiași clase: lecțiile sunt disponibile; atelierul este ascuns. Deschide o lecție, execută SQL, reîncarcă și verifică progresul.
  • Profesor din altă clasă, fără apartenență la clasa curentă: accesul se oprește. Dacă este doar membru al clasei curente, atelierul rămâne ascuns.
  • Schimbă contul și verifică separarea proiectelor. Exportă lucrările înainte să ștergi datele browserului. Separarea locală nu reprezintă criptare împotriva altcuiva care controlează același profil de browser.
  • Modifică biblioteca SharePoint și actualizează lista. O lucrare deja începută își păstrează enunțul inițial; pentru noua definiție, folosește Pornește de la început după exportarea progresului.

Dacă nu se conectează

Verifică identificatorii, tipul SPA și URI-ul NAA, acordul administratorului, politicile Teams și existența unei clase educaționale în Microsoft 365. Un grup Teams obișnuit nu este suficient pentru verificarea claselor prin Education API. Folosește un client Teams actualizat care suportă NAA. Pentru 403 verifică permisiunile aplicației și ale fișierului; pentru 404 verifică numele și poziția bibliotecii.

Prima probă în contul real al școlii rămâne necesară: testele livrate folosesc răspunsuri Microsoft simulate. Dacă infrastructura școlii refuză NAA, aplicația afișează eroarea și nu acordă rolul de profesor.
