În Atelier de lecții pregătești propriile enunțuri, baze și indicii, apoi le exporți într-o bibliotecă.
  1. Execută interogarea inițială.
  2. Selectează un tabel din stânga și deschide Structură sau Date.
  3. Creează un tabel vizual și urmărește comanda generată.
  4. Exportă proiectul înainte să schimbi calculatorul.
Exerciții: afișează elevii din XI A; ordonează elevii după nume; calculează media notelor pe elev.
SELECT e.nume, ROUND(AVG(n.nota), 2) AS media
FROM elevi e JOIN note n ON n.elev_id=e.id
GROUP BY e.id;
Dialect: SQLite. Folosește INTEGER PRIMARY KEY pentru identificatori automați, nu sintaxa MySQL AUTO_INCREMENT. Tipurile de bază: INTEGER, REAL, TEXT, BLOB, NUMERIC. Datele calendaristice pot fi stocate ca TEXT (AAAA-LL-ZZ).
În formularele de date, alege Valoare, NULL sau Implicit / automat. Textul gol este distinct de NULL. Listele de referințe afișează cheile existente. Verifică SQL-ul înainte de Aplică. Resetarea cere confirmare. SQL rulează pe o copie: la eroare sau oprire se păstrează starea anterioară.
